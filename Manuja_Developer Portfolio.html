About me

Hi, I’m Manuja! I’m a passionate developer and technology enthusiast based in Sri Lanka, with a strong focus on software development, custom system configurations and computer science.

I’ve built desktop applications and worked with C#, SQL databases and shell scripting. I enjoy diving deep into command-line automation, custom Linux desktop environments (like Arch Linux and Hyprland) and optimizing systems for performance. When I’m not coding or tweaking configuration files, I’m usually solving problems in mathematics and ICT or exploring open-source software tools.
